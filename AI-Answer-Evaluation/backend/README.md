# Backend Service

This backend package is the foundation for future modules such as OCR processing, grading workflows, RAG retrieval, vector storage, reporting, and teacher review tools.

## Planned Modules

- API routes under app/api
- Service layer under app/services
- Data models under app/models
- Database access under app/database
- Request/response schemas under app/schemas
- Shared helpers under app/utils and app/core

The current implementation is intentionally limited to scaffolding and placeholder files.
